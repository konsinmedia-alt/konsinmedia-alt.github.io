Konsin Media Content Manager

An internal content-management tool by Konsin Media, operated by Sigma Media.

Owner: Sigma Media · Brand: Konsin Media · Contact: lightbodyfrushour@gmail.com

What this app does

Konsin Media Content Manager is a private, internal tool used only by Konsin Media and its authorized staff to manage the company's own YouTube channels. It works with the YouTube Data API to:

  • upload video files to channels owned by Konsin Media,
  • view and edit video metadata (titles, descriptions, thumbnails, scheduling),
  • manage publish scheduling for internal content production.
This is not a public app. It is intended solely for internal use by Konsin Media / Sigma Media. It is not offered to, and does not collect data from, external users.

About the name

The application name shown here (Konsin Media Content Manager) is the display name used on the OAuth consent screen. Internally, the project may also be referred to by its development codename. The application is not affiliated with, endorsed by, or owned by Google LLC or YouTube.
